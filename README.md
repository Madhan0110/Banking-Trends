# Banking-Trends
## Bank Customer Data Analysis

This repository contains an SQL project analyzing bank customer data, using a sample dataset and SQL queries for insights.

## Project Highlights
- Customer segmentation and average balances analysis
- Account relationship extraction and transaction categorization
- SQL-based deduplication, event message linking, and interest rate tracking

## Technologies
- SQLite, SQL
- Python (Colab, pandas, tabulate)

## Future Extensions
- Predictive analytics (churn, segmentation)
- Visualization dashboards (Power BI, Tableau)
- Time series, risk scoring, fraud detection

See the notebook `Banking__Insights.ipynb` for detailed steps and results.
